# C 區：固定視角線框氣流

入口：http://127.0.0.1:8765/C-Web/Cweb-3d.html 。原 Cweb.html 保留，右下有 3D 比較入口；原 responsive 修改保留。

此版本延伸原 2D 的深色、藍白線條風格，採固定正交俯斜視角，沒有旋轉、縮放或寫實材質。空間線框來自實際模型。移動粒子、光暈與拖尾為主要內容。

## 操作與分鏡

可切早晨／午間／夜晚／完整分鏡。三個時段各循環對應 30 秒；完整分鏡 90 秒。底部可跳段、暫停、重播；空白鍵暫停，R 重播。

依使用者簡報第 16–18 頁，六段為：

| 時間 | 分鏡 | 視覺 |
|---|---|---|
| 0–15 秒 | 進場與情境建立 | 午間窗邊暖流、床位熱區 |
| 15–30 秒 | 空間掃描與數據呈現 | 環境數據、新風逐漸啟動 |
| 30–45 秒 | 睡前情境展演 | 夜色、窗簾漸閉、暖流減弱 |
| 45–60 秒 | 睡眠中情境展演 | 低亮、穩定新風與床位狀態 |
| 60–75 秒 | 清晨喚醒情境展演 | 清晨背景、窗簾開啟、柔和暖流 |
| 75–90 秒 | 完成與回饋 | 牆面投影收斂成平穩呼吸線 |

背景、卡片、按鈕、文字與線框協調配色。白噪音、車聲、早安語音僅以分鏡文字提示，本版不輸出音訊。既有窗景 repo 保持獨立；本頁只显示窗框、窗簾與熱流，不播放窗景影片。

## 新風位置與熱流

使用者後續提供 1788434914125(1).jpg 並更正「應該只有新風」，因此取消先前假設的冷氣、主臥回風與主臥排風口。主臥只保留一個新風進氣口。

進氣點依圖中主臥左下、床頭側定位。對照原模型座標，初始 viewer 位置為 [-1.75,2.50,1.25] 米。平面採比例對照，並非施工精度；2.50m 安裝高度仍是可調展示假設。圖中紅色排氣點在其他區域，沒有搬入主臥。座標在 scene-config.js，側欄可微調水平位置。

藍色粒子表示新風；窗邊黃橘熱流沿受熱窗面緩慢上升，再於上方向室內擴散，午間較強、夜間窗簾關閉後減弱。窗邊熱負荷獨立設定，並非宣稱數位窗景產生日照。新風溫度可調；送風比床位暖時會轉暖色且可能提高床位溫度。新風不是冷凍空調，床位參考值只用於狀態判讀，不會讓新風自動製冷。

紅點從原模型 Light_* 發光材質網格定位，鄰近 25cm 的点合併為 4 組。它是光源辨識標記，非現場照度量測，可獨立開關。

## 模型與交付檔案

線上版只包含必要的 C-bedroom-wire.glb；下列完整模型與來源檢查紀錄保留在本機工作區。

來源為使用者提供的 0820_寶舖大安基地.3ds 與相鄰材質，依簡報第 15 頁及後續平面圖比對 C 位於 D 廚房下方、G 上方。1707 個 mesh matrix 皆為單位矩陣。擷取原座標 X 1165–1573、Y 474–800、Z 0–270 公分；跨界三角形裁切並插值 UV。原點 [1369,637,4.83726]，公分轉米，再轉 glTF Y-up。

原床組位於主臥外 [901,557] 附近，C 兩床頭櫃之間沒有床網格。經獨立渲染辨識後，沿用原床組 102、103、104、1294、1295、1296，旋轉 90 度並依簡報定位兩櫃之間。此校正有記錄，不宣稱是原檔案擺放。頁面為避免被單三角網干擾氣流，床組外框按原網格尺寸包絡簡化。

- assets/C-bedroom-wire.glb：約 2.9MB 的線框用簡化模型，不含寫實貼圖。
- assets/C-bedroom.glb：獨立完整主臥模型，保留原床組、家具與內嵌材質。
- assets/C-bedroom.blend：可編輯完整模型，來源 ID 與位置校正保留於自訂屬性。
- assets/C-extraction.json：擷取物件與床組變換記錄。
- assets/source-inventory.json、plan-z*.png：原座標檢查紀錄。
- assets/source-furniture-check.png：辨識原床墊及被單的渲染。
- vendor/THREE-LICENSE.txt：Three.js 授權。

重建依序執行 tools/build_model.py、tools/place_source_bed.py、tools/build_wire_model.py，使用 Blender --background --factory-startup --python。完整主檔與線框衍生檔分開，不觸碰使用者正在開啟的 Blender 場景。來源路徑寫於 tools/inspect_model.py。

## 模擬界線

這是即時視覺展示，非 CFD、非實測，沒有感測器或設備控制連線。床位色彩、溫濕度、噪音、窗簾、投影與流線共用同一時間狀態。新風溫度與窗邊熱負荷影響腳本溫度。流線與粒子為說明方向的動畫，不表示已計算真實流場、壓差或換氣量。

驗證：實際瀏覽器已確認模型載入、六段跳轉、早午晚配色、窗簾開合、暫停時時間不變，以及 390px 窄版無橫向溢出。粒子採獨立累積位移，流速變化不會使位置跳躍；新風流速約為先前版本六分之一。


新風粒子更新：移除平行流束、固定藍色曲線與箭頭，改用獨立速度、逐漸散開與淡出的粒子。此為氣流混合的視覺示意，未增加物理解算器。


投影更新：床上方改為大片 16:9 牆面投影，示意尺寸 3.0 × 1.6875 米，可於 scene-config.js 校準。畫布同步為 768 × 432，並提高早晨背景與介面亮度、線框對比。



### 分鏡節奏補強
- 完整版從進場開始；15–24 秒床面單次掃描，投影熱區與溫度／濕度／噪音依序浮現。
- 清晨以分鏡時間控制背景亮度，18 秒內漸亮；暫停與跳段保持一致。
- 75–84 秒投影數據淡出並交疊成呼吸線與早安文字；側欄保留本次模擬前後溫度，不推論真實睡眠品質。
- 睡眠段降低投影及標籤亮度，保留慢速新風。聲音仍採靜音示意。

日間配色修正：早晨／午間改為暖白與中性灰背景，深藍線框與新風粒子保持辨識；夜晚維持深藍。日間牆面投影改暖白底、深色文字並提高不透明度，避免整幅投出藍色夜景。

分鏡二地板更新：15–24 秒以橫跨地板的掃描線逐步揭示完整熱力圖，保持至第二幕結束。進場不顯示地板熱力圖；睡前逐漸降低亮度。地板使用獨立紋理，暫停及跳段皆依分鏡時間重建。

地板熱感採相對示意色：室內藍色，僅窗邊局部淡黃，圖例不再標示絕對溫度；側欄溫度數值不變。

分鏡敘事：第二幕分為開始掃描、熱區浮現、掃描完成三個字幕節點，掃描期間弱化牆面投影與標示，24 秒後依序帶出數據。新增可開關的瀏覽器中文合成導覽語音，預設靜音；暫停與跳幕取消上一段語音。語音是正式配音前的節奏原型，音色取決於本機已安裝語音。

VoAI 三幕錄音已接入：assets/audio 的三段 WAV，怡婷 Neo、語速 1、音調 0。保留 90 秒動畫，導覽分三幕，錄音於 10／30／65 秒播放；開關、暫停、跳幕與重播依展示時間同步。預設靜音，字幕始終顯示。不再使用瀏覽器合成語音。

已接入使用者提供 ANLB 語音球：vendor/anlb-orb/restored-orb.js 原樣保留並附 MIT LICENSE／UPSTREAM。voice-orb.js 使用單一 AudioContext 分析三支本機 VoAI 音檔，每支來源只建立一次，實際 RMS 驅動起伏；暫停與段間停頓維持 thinking。完整 90 秒結束停播並回 idle，重播可再次開始。WebGPU 無法初始化時隱藏球，保留字幕與配音。
