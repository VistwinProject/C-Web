大字幕：`captions.css` 提供固定的大字幕欄位；`c-captions.mjs` 按三段實際音檔起訖切換短句，靜音時照常顯示。句內切點依文字長度估算，非逐字辨識校準。字幕空檔留白；淡入淡出約 0.8 秒（短句以時長四分之一為上限），使用展演時間，暫停、跳幕及重播不會留下舊字幕；減少動態效果偏好會取消淡化。字幕測試：`node --test tools/test_captions.mjs`。

# TouchDesigner OSC 三幕同步

啟動 `python tools/osc_bridge.py`，HTTP 轉送服務為 127.0.0.1:8766。網頁使用本機 8765 HTTP 服務。

目標預設 `127.0.0.1:8970`，OSC 位址 `/c/scene`，型別 int32：
- 01 最懂你的空間 = 0
- 02 睡前到入睡 = 1
- 03 起床與回看 = 2

自動播放在劇情時間 30／60 秒（含入場段的實際時間 56／86 秒）邊界前預設 100ms 發送，可調 0–1000ms；這是人工校準值，非已測得的 TD 延遲。手動跳幕立即送目標值；第三幕中再按 03 仍從第三幕開始，不跳回第一幕。重播送起始幕狀態。完整分鏡結束仍停在第三幕，按 01 或重播才回 0。暫停保留已送狀態。

網頁首次載入會同步目前幕。面板可手動測試 0、1、2。新版設定使用獨立儲存鍵，不沿用舊 9000／熱區位址。關閉自動同步不送額外幕值。發送失敗不重試；有進行中的請求時只保留最新待送狀態，避免舊幕堆積。UDP 不保證接收；HTTP 往返時間不等於 TD 接收延遲。

TD OSC In CHOP：Active On、Protocol Messaging (UDP)、Network Port 8970、OSC Address Scope *、Queued Off。觀察 c/scene 通道是否依序 0 → 1 → 2 → 0。

C、D 共用一致的底部播放列樣式 `player-controls.css`。右側資訊數據不隨展演降低透明度。

## 腳本運鏡

`camera-shots.mjs` 採「全景 → 台詞重點特寫 → 全景」；每次推入／退出約 1.2–1.4 秒，特寫期間定住，沒有環繞或持續漂移。冷氣約 1.5 倍、窗邊約 1.4 倍、床位約 1.3 倍，鏡頭瞄準設備實際座標。第一幕以設計先行的文案強調冷氣、窗邊受熱與床位配置；第二幕僅保留一次床位觀察：劇情第 34–39 秒緩慢推近至 1.12 倍，定住至 51 秒，第 51–56 秒退回全景。第三幕與結尾固定全景，以晨光、窗簾、氣流及字幕呈現變化。時間依語音段落規劃，並非逐字強制對齊。

`camera-timeline.mjs` 以展演時間平滑插值；暫停、跳段與重播得到一致構圖。減少動態效果偏好時固定全景。近景時將右側資訊下方的模型線條漸隱，資訊本身不淡化，也不新增側欄底色。

驗證：`node --test tools/test_camera.mjs tools/test_playback.cjs`。

2026-09-27 更新：聚焦設備以 3.2 秒週期柔和明暗變化，效果使用展演時間，暫停即定住，跳段及重播可還原；減少動態效果時保持穩定強調。
